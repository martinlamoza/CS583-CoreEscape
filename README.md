# Core Escape

CS 583 - Game Programming
San Diego State University

## Project Member

Martin Lamoza - Individual Developer

## Game Description

Core Escape is a 3D obstacle and escape game developed in Unity.
The player navigates an energy facility, collects energy cores,
and avoids moving security obstacles. Once all energy cores are
collected, the player can reach the exit portal to complete the level.

## Development Responsibilities

- Gameplay programming and player controls
- Camera movement and tracking
- Level and environment design
- Materials, lighting, and animation
- Obstacle mechanics and collision detection
- User interface and menu development
- Gameplay testing and debugging

## Controls

| Key | Action |
| --- | --- |
| W | Move forward |
| A | Move left |
| S | Move backward |
| D | Move right |

2. Open Assets/Scenes/Level01.unity.
